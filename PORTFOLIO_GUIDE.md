# Portfolio Submission Guide

This guide explains how to organize and verify your final portfolio submission for the Spatial Data course.

---

## Why This Exists

During the course you were allowed to rename files and reorganize your assignment folders. That flexibility made it hard to verify what you completed. For your final portfolio submission, **you must restructure your work to match the original assignment layout** so it can be graded consistently.

The script `check_portfolio.py` is your tool for doing that. Run it, look at the output, rename and move files until everything shows ✅, then open `progress_checklist.txt`, fill in your score, and push.

> **Your submission is not complete until both of these are true:**
> 1. Every notebook you intend to submit shows ✅ in the expected structure.
> 2. `progress_checklist.txt` exists in your repo root **with a number (0–10) filled in** — not the default `__`. If you did no work on the course, enter `0`.

---

## What You Need to Submit

Your repository must contain a folder called `completed_assignments/` at the root level and a file called `progress_checklist.txt` at the root level. Inside `completed_assignments/`, your finished notebooks should be arranged to **exactly match the original assignment structure** — same folder names, same file names, same nesting.

```
your-repo/
├── completed_assignments/
│   ├── 01-Python_Foundations/
│   │   ├── 01-Working_with_Data_Basic/
│   │   │   ├── Assessments/
│   │   │   │   └── 02a-mini_quiz.ipynb
│   │   │   └── Lessons/
│   │   │       └── ...
│   │   └── ...
│   ├── 02-Missile_Geometry_101/   (or 02-Missile_Geometry_202/)
│   │   └── ...
│   └── 03-Data_Manager/
│       └── ...
├── check_portfolio.py
├── progress_checklist.txt   ← generated by the script; you must fill in your score
└── ... (rest of your repo)
```

---

## How to Run the Script

From the **root of your repo** (not inside any subfolder), run:

```bash
python check_portfolio.py
```

No external libraries are required — it uses only the Python standard library.

---

## Reading the Output

The script prints three sections.

### 1. Expected Structure

A full tree of every notebook you may need to submit, with a status marker next to each file:

```
completed_assignments/
├── 01-Python_Foundations/
│   ├── 01-Working_with_Data_Basic/
│   │   ├── Assessments/
│   │   │   └── ✅ 02a-mini_quiz.ipynb
│   │   └── Lessons/
│   │       ├── 01-Lists/
│   │       │   └── ❌ 01-Lists.ipynb
```

| Marker | Meaning |
|--------|---------|
| ✅ | File found at the exact expected path |
| ❌ | File missing — rename or move it here |

### 2. Your Current Tree

Shows everything that currently lives inside your `completed_assignments/` folder, regardless of whether it is in the right place. Use this to find files that exist but are in the wrong location.

### 3. Summary

A per-section count and progress bar, plus the completion goal for each section:

```
  01-Python_Foundations
    15/38  [███████████████░░░░░░░░░░░░░░░░░░░░░░░]
    Goal: complete 40–50% of notebooks

  Total: 47/130 notebooks found
```

## Completion Requirements

| Section | Notebooks | Requirement |
|---------|-----------|-------------|
| `01-Python_Foundations` | 38 | Complete **40–50%** (roughly 15–19 notebooks) |
| `02-Missile_Geometry_101` | 11 | Complete **all 11** + include your working project |
| `02-Missile_Geometry_202` | 60 | Complete **all 60** *(choose 101 or 202, not both)* |
| `03-Data_Manager` | 21 | Complete **all 21** |

> You will complete **either** `02-Missile_Geometry_101` or `02-Missile_Geometry_202`, not both.

## Step-by-Step Workflow

1. **Create the folder** if it does not exist yet:
   ```bash
   mkdir completed_assignments
   ```

2. **Run the script** to see what is expected vs. what you have:
   ```bash
   python check_portfolio.py
   ```

3. **Copy or move** your completed notebooks into the correct paths shown under *Expected Structure*. The folder and file names must match exactly.

4. **Re-run the script** after each round of changes. Repeat until every notebook you intend to submit shows ✅.

5. **Fill in your score.** Open `progress_checklist.txt` (created in your repo root by the script) and replace `__ / 10` with your self-reported progress score:
   - `10` = 100% complete
   - `0` = no work done — **do not leave the placeholder blank; enter `0`**
   - Any value in between reflects your honest estimate of overall completion.

6. **Commit and push** both `completed_assignments/` and `progress_checklist.txt`.

## Common Issues

**"completed_assignments/ folder not found"**
Create the folder at your repo root: `mkdir completed_assignments`

**A file shows ❌ but I know I did it**
The path or filename doesn't match exactly. Check for:
- Capitalization differences (`lists.ipynb` vs `01-Lists.ipynb`)
- Extra or missing numbers in the prefix (`01-Lists` vs `Lists`)
- Wrong parent folder name

**I see files in "Your Tree" that aren't matching**
Your files are in `completed_assignments/` but not at the exact expected path. The *Expected Structure* section shows exactly where each file needs to be — move it there.

**I completed a notebook but it still shows ❌ after moving it**
Double-check the full path. The script matches on exact relative paths, so every folder level must be correct, not just the filename.
